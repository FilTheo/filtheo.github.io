Hospitality AI API (click for details)

AI-powered Q&A generation and operational manual automation

What it does: A FastAPI backend system that automates the creation of Q&A content and operational manuals for hospitality businesses. The system processes raw operational documents and transforms them into structured, queryable knowledge bases that power AI assistants.

The Agentic Part: The system implements autonomous AI agents that perform two core functions: (1) Q&A Generation Agent - analyzes operational documents, policies, and procedures to automatically generate comprehensive question-answer pairs covering common guest inquiries, staff procedures, and edge cases. This agent identifies key information points and creates diverse, well-structured Q&A content. (2) Manual Generation Agent - transforms raw documentation into formatted, contextually aware manuals. The agent understands document structure, extracts relevant sections, and generates coherent procedural guides that can be delivered in multiple formats (Markdown, HTML, PDF).

Key Capabilities: Automatic extraction of Q&A pairs from unstructured documents, intelligent manual structuring and formatting, context-aware content generation that maintains consistency across generated materials, stateful conversation support for deployed assistants, and API-driven access for seamless integration with existing hospitality systems.

DJ35 Roster Optimizer (click for details)

AI-powered scheduling with multi-stage constraint optimization

What it does: An intelligent scheduling system that automates the creation of monthly DJ rosters by processing natural language availability, applying complex business constraints, and optimizing assignments to minimize conflicts while maximizing coverage and preferences.

The Agentic Part: The system employs a pipeline of specialized AI agents: (1) Extraction Agent - parses free-form text from DJs describing their availability (e.g., "I'm free all weekends except the 15th, and weekday evenings") and structures this into machine-readable availability data. (2) Optimization Agent - applies constraint-based reasoning to generate conflict-free schedules, balancing multiple objectives like fair distribution, skill matching, and preference satisfaction. This agent handles the combinatorial complexity of assigning multiple DJs to multiple dates while respecting all constraints. (3) Verification Agent - validates proposed assignments against business rules, identifies potential conflicts, and generates scenario comparisons showing the trade-offs between different scheduling options to support human decision-making.

Key Capabilities: Natural language availability parsing, multi-objective constraint optimization, interactive schedule preview and editing, automated conflict detection and resolution, scenario-based decision support for human oversight, and drag-and-drop roster management for manual adjustments.

Chatbot Council (click for details)

Multi-agent deliberation system for enhanced reasoning

What it does: A sophisticated multi-agent system where multiple AI models collaborate to answer complex questions through structured deliberation. Unlike single-LLM responses, this system leverages collective intelligence by having diverse agents reason, debate, and refine answers together. Users can select which open-source models to include in the council, customizing the expertise and perspectives brought to each deliberation.

The Agentic Part: Each AI agent operates as an independent "council member" with distinct reasoning styles and areas of expertise. The system orchestrates a multi-round deliberation process where: (1) agents independently analyze the question and propose answers, (2) agents vote on each other's responses, (3) an arbiter agent evaluates the arguments and eliminates weaker perspectives, and (4) surviving agents refine their answers based on the deliberation. This process continues until a final synthesized answer emerges from the strongest perspectives. Users have full control over which models participate, allowing them to tailor the council's capabilities to specific domains or use cases.

Key Capabilities: Configurable model selection from open-source providers, parallel independent reasoning, peer review and voting, arbiter-driven elimination of weak arguments, iterative refinement through multiple rounds, ensemble synthesis of final answer, and real-time streaming of the entire deliberation process so users can watch the AI "think" together.
